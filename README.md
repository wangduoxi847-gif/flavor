# flavor

不署名的静态工具实践集。中文内容，适配桌面与手机。

## 页面内容

- 关于作品
- 实践与工具：AI 工作流、本地文件自动化整理、PowerShell 玩机；每项按“问题 → 做法 → 结果”介绍，并附可见实例
- 合并清单使用明确标注的演示状态；文件归档与只读脚本使用通用测试文件，页面展示实际核验结果
- 文件演示逐份展示旧名称与分类后的新名称，并验证复制前后的内容一致；保留源文件
- 只读脚本位于 `examples/Get-FileInventory.ps1`，页面完整展示同一份代码、实测清单与三条常用查询命令
- 技能：对应到具体任务和可复用的步骤
- 作品展示：flavor 建站案例（真实桌面与手机截图）、任务交接单生成器、批量文件命名预览器

## 作品与验证

- 建站案例说明需求、实现分工、响应式检查与已完成版本的部署验收，不公开账号或私人资料。
- 交接单生成器按六栏生成 Markdown；空栏目标记为“未确认”，支持通用示例、清空和复制。
- 命名预览器按日期、主题、序号生成对照；检查日期、序号、Windows 文件名及本次输入的重复与冲突，不读取文件、不执行重命名。
- 两个工具均仅在当前浏览器页面内处理输入，不上传、不持久化；刷新恢复通用示例。
- 核心逻辑与边界检查：`node --test tests/tools-core.test.cjs`。

## 技术

原生 HTML、CSS、JavaScript，无框架、无后端、无构建步骤。字体使用系统字体；装饰图形由 CSS 绘制，无外部字体、分析脚本或第三方资源依赖。

页面文件为 `index.html`、`assets/` 和 `.nojekyll`。可直接打开 `index.html` 浏览，也可用任意静态预览工具。

## GitHub Pages

部署方案为公开仓库的 `main` 分支根目录，使用 GitHub Pages 默认域名，无需购买域名或付费服务。

所有资源均使用相对路径，兼容项目站点的子目录。

## 修改

- 文案和页内链接：`index.html`
- 颜色、排版和响应式规则：`assets/styles.css`
- 年份和导航位置提示：`assets/main.js`

关闭 JavaScript 后仍可阅读案例与实践内容、使用页内导航；两个交互工具需要 JavaScript。工具表单不连接后台，不收集访客输入。
