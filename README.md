# flavor

不署名的静态工具实践集。中文内容，适配桌面与手机。

## 页面内容

- 关于作品
- 实践与工具：AI 工作流、本地文件自动化整理、PowerShell 玩机；每项按“问题 → 做法 → 结果”介绍，并附可见实例
- 实例采用通用占位内容：合并清单、命名与分类前后对比、已在 Windows 本机运行验证的三条只读 PowerShell 命令
- 技能：对应到具体任务和可复用的步骤

## 技术

原生 HTML、CSS、JavaScript，无框架、无后端、无构建步骤。字体使用系统字体；装饰图形由 CSS 绘制，无外部字体、分析脚本或第三方资源依赖。

页面文件为 `index.html`、`assets/` 和 `.nojekyll`。可直接打开 `index.html` 浏览，也可用任意静态预览工具。

## GitHub Pages

部署方案为公开仓库的 `main` 分支根目录，使用 GitHub Pages 默认域名，无需购买域名或付费服务。

所有资源均使用相对路径，兼容项目站点的子目录。

## 修改

- 文案和页内链接：`index.html`
- 颜色、排版和响应式规则：`assets/styles.css`
- 年份和导航位置提示：`assets/main.js`

关闭 JavaScript 后仍可阅读全部内容、使用页内导航。页面没有表单，不收集访客提交的数据。
